# MIDOV — концепт сайта кофейни

Демонстрационная страница: как мог бы выглядеть сайт кофейни MIDOV
(Владикавказ) с настоящим меню, шестью точками и работающим заказом.

**Это концепт, а не официальный сайт MIDOV.** Заказ со страницы никуда
не уходит: корзина считает сумму и показывает подтверждение, ни одного
сетевого запроса при этом не делается. Фотографии напитков — образцы для
макета, а не предметная съёмка кофейни. Съёмка залов, фасадов и гостей —
собственные фотографии MIDOV, выложенные ими в открытый доступ.

Страница статическая: ни сборки, ни зависимостей, ни бэкенда.
Открывается двойным щелчком по `index.html`.

    index.html      разметка и стили первого экрана
    css/            стили
    js/             меню, корзина, точки, оформление заказа
    assets/         фотографии, ролики первого экрана

Опубликовано через GitHub Pages: https://sarmtem-t7.github.io/midov-demo/
